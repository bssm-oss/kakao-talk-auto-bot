# 사용자 플로우

1. 메인 화면에서 알림 접근 권한 허용
2. 응답 설정 화면에서
   - 내 이름
   - 페르소나
   - 내 말투 예시
   - 학습된 내 말투 사용/수정/초기화
   - `응답 엔진` 섹션의 Gemma 4 로컬 엔진 상태 확인
   - 기본 트리거 성향
   - 최근 내 발화 기준 자동 페르소나 힌트 적용
   를 저장
3. 대상 방 관리 화면에서 자동응답할 방 추가
4. `방 메모리 편집` 화면에서
   - 방 메모리
   - 수동 방 말투
   - 학습된 방 말투 사용/수정/초기화
   - 잘못 배운 방 말투의 원본 대화 삭제
   - 자동 생성되는 방 메모리 요약 확인
   - 허용/차단 발화자
   - 고정 답장 목록
   - 트리거 조건
   을 저장
5. CSV 이력을 방에 가져와 과거 맥락 보강
6. 메인 화면에서 AI 자동 답장 ON/OFF 제어
7. 메인 화면에서 수신/전송/스킵/실패 누적 상태와 최다 실패 원인 확인
8. 메인 화면에서 로그 복사 시 개인정보 가리기 여부 선택
9. 메인 화면에서 최근 로컬 로그 삭제
10. 메인 화면에서 시스템/라이트/다크 테마 전환

현재 메인 화면, 응답 설정 화면, 대상 방 관리 화면, 방 메모리 화면은 같은 플로우를 유지한 채 평평한 카드, 절제된 강조색, 정돈된 간격과 버튼 계층으로 시각 정리를 적용합니다. 응답 설정 화면은 로컬 Gemma 엔진 상태와 그라운딩 기준을 바로 확인할 수 있습니다.

에뮬레이터에서는 Gemma/LiteRT-LM 실행이 지원되지 않으므로 응답 설정 화면에서 실기기 필요 상태를 표시하고 모델 다운로드를 막습니다. 로컬 모델 다운로드와 생성 품질 확인은 ARM64 Android 실기기에서 진행합니다.

로컬 엔진은 현재 메시지, 사용자 직접 예시, 수동 방 말투, 최근 방 이력, 방 메모리, 자동 메모리 요약, CSV로 가져온 과거 맥락을 함께 보고 짧은 한국어 답장을 만들거나, 확신이 낮으면 답장을 생략합니다.

Gemma가 만든 첫 문장을 바로 보내지 않고 primary/style_rewrite/human_style/compact 후보 lane 을 함께 만들고 점수화해 최종 답장을 고릅니다. human_style 후보는 사용자 직접 예시와 수동 방 말투를 더 강하게 따라 실제 사용자가 보낼 한 문장처럼 만들기 위한 경로입니다. 후보가 모두 약하면 더 짧은 emergency 후보까지 평가합니다. 평가는 AI 메타 문구, 프롬프트 반복, 과한 추측, 방 말투 일치, 방 메모리 근거를 기준으로 합니다.

일정/시간처럼 방 메모리나 최근 대화에서 근거가 분명한 질문은 규칙 기반 후보도 함께 만들어집니다. 이 후보도 Gemma 후보와 같은 품질 기준으로 평가되며, 근거가 확실하면 모델 응답을 기다리지 않고 짧게 답할 수 있습니다.

`그거 됐어?` 같은 애매한 말은 최근 대화에서 가능한 대상이 둘 이상 보이면 단정하지 않고 확인 질문 후보를 만듭니다.

말투 우선순위는 사용자 직접 예시, 수동 방 말투, 가져온 내 발화, 앱에서 관측한 내 발화, 자동 방 말투, 최근 대화 사실 순서입니다. 친구방에서는 더 가볍게, 학교/팀 단톡에서는 더 단정하게 답하도록 방별 스타일을 별도로 저장합니다.

최종 답장 선택 단계에서도 방 말투를 다시 검사합니다. 친한/반말 방에서 과한 존댓말 후보가 나오거나 학교/팀/존댓말 방에서 반말 후보가 나오면 품질 점수가 낮아져 다른 후보가 우선 선택됩니다.

학습된 내 말투와 방 말투는 샘플 수 기반 신뢰도와 함께 표시됩니다. 수동으로 적은 예시와 방 말투가 있으면 자동 추출값보다 먼저 적용됩니다. 신뢰도가 낮은 학습값은 답장 생성 프롬프트에서도 보조 힌트로만 다루며, 프롬프트에는 신뢰도 라벨, 점수, 샘플 수가 같이 들어갑니다. 방 말투 화면은 낮은 신뢰도, 수동 수정, 꺼짐 상태에 따라 `수정 초기화` 와 `학습 원본 삭제` 중 어떤 reset 경로를 써야 하는지 함께 안내합니다.

보내기 전 승인 UI는 두지 않습니다. 전역/방별 OFF 상태가 아니고, 방 설정/발화자 조건/트리거/AI 판단 조건을 통과하면 자동으로 답장을 전송합니다.

카카오톡 알림이 같은 메시지를 짧은 시간 안에 반복 갱신해도 같은 방/발화자/메시지에 대한 자동 답장은 한 번만 생성합니다. 같은 방 안에서는 답장 생성과 전송을 순서대로 처리합니다.

OFF 상태에서는 답장만 멈추고, 메시지 수집과 세션 갱신은 유지합니다.

로그 복사는 기본적으로 방 이름, 발화자, 메시지 본문을 가리고, 전송 실패 reason 같은 운영 원인만 남깁니다. 사용자가 원본 복사를 선택하면 복사 직전 개인정보 포함 가능성 경고를 보여줍니다.

로그 삭제는 로컬 로그 파일만 지웁니다. 답장 통계, 대상 방, 방 메모리, 학습된 말투 설정은 유지됩니다.
